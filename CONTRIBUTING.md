# Contributing to the AuditLane public repository

Thank you for your interest in AuditLane.

AuditLane is a proprietary product. This repository is primarily used as its public GitHub presence and does not contain the private application source code.

## What is useful here

Contributions and feedback may include:

- documentation corrections,
- reproducible product or UX issues,
- accessibility feedback,
- suggestions that improve clarity of evidence and reporting,
- feedback on public examples or terminology.

## Before opening an issue

Please include enough context to reproduce or understand the problem:

- what you were trying to do,
- what you expected,
- what happened instead,
- browser/device information when relevant,
- screenshots only when they do not expose private or sensitive information.

## Security

Do not publish credentials, tokens, private URLs, customer data, exploit details, or other sensitive material in a public issue.

If a report could create a security risk, keep the details private and use an official private contact channel when one is published for AuditLane.

## Source code

The production source code, internal infrastructure configuration, secrets, and private operational documentation are not part of this public repository.

## Language

The first AuditLane product version and its public product documentation are written in English.
